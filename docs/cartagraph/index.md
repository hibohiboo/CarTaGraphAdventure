# 遊びの共通の形

どのシーンでも共通の、プレイヤーがすることを決める。シーンの中身（何が描かれ、そのシーンにどのカードを用意するか）はシナリオが決める。手札には、キャラクターが持ち込むカードもある（[手札](../glossary.md#手札)）。決めた理由は[ロードマップのデザイナーノート](../notes/roadmap.md)にある。

## シーンですること

プレイヤーは、シーンごとに次の2つのどちらかをする。

- **手札を出す** — 手札から1枚を出す。出したカードの結果のとおりに、次のシーンへ進む
- **GM へ提案する** — 手札に無いことを文章で提案する

## 提案

- 提案も、見た目は手札と同じカードにする（前のゲームの見せ方を踏襲する）
- 提案は、遊んでいるゲームの外へ、開発への要望として届く
- いまは GM がいないので、提案に答える人がいない。提案したシーンは「提案待ち」になり、提案が実装されるまで先へ進めない
- 提案が実装されたら、提案したシーンの続きから遊べる。そこまでに遊んだことはそのまま残る

## キャラクター

- キャラクターは、まず名前だけを持つ
