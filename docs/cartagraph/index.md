# 遊びの共通の形

どのシーンでも共通の、プレイヤーがすることと、ビートの見せ方を決める。シーンとビートの中身（何が描かれ、どのビートにどのカードを用意するか）はシナリオが決める。手札には、キャラクターが持ち込むカードもある（[手札](../glossary.md#手札)）。決めた理由は[ロードマップのデザイナーノート](../notes/roadmap.md)にある。

## シーンですること

1つのシーンは、ビート（プレイヤーが1回選ぶまでの一区切り）の並び。プレイヤーは、ビートごとに次の2つのどちらかをする。

- **手札を出す** — 手札から1枚を出す。出したカードの結果のとおりに、次のビートへ進む。カードには、出すときにキャラクターの名前を書くものがある。名前を書いて出すと、それがキャラクターの名前になる
- **GM へ提案する** — 手札に無いことを文章で提案する

## 提案

- 提案も、見た目は手札と同じカードにする（前のゲームの見せ方を踏襲する）
- 提案は、遊んでいるゲームの外へ、開発への要望として届く
- いまは GM がいないので、提案に答える人がいない。提案したビートは「提案待ち」になり、提案が実装されるまで先へ進めない
- 提案が実装されたら、提案したビートの続きから遊べる。そこまでに遊んだことはそのまま残る

## キャラクター

- キャラクターは、まず名前だけを持つ
- 名前は、前後の空白を除いて1〜10文字。文字は見た目の1文字（絵文字や結合文字も1文字）で数える

## ビートの見せ方

- ビートには、紙面と会話の2つの見せ方がある。紙面は地の文を読み、会話は相手（NPC）の台詞を読む
- 会話のビートでは、相手の台詞を1つずつ読み切ってから、手札を出す。出したカードに自分の台詞があれば、会話に足される
- 会話は、同じシーンの中で続けて残る（紙面のビートの文は入らない）。シーンが変わると途切れる

決めた理由は[遊びの共通の形のデザイナーノート](../notes/cartagraph.md)にある。
