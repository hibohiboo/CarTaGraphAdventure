# 遊びの共通の形

どのシーンでも共通の、プレイヤーがすることを決める。シーンの中身（何が描かれ、どのカードが配られるか）はシナリオが決める。決めた理由は[ロードマップのデザイナーノート](../notes/roadmap.md)にある。

## シーンですること

プレイヤーは、シーンごとに次の2つのどちらかをする。

- **手札を出す** — シナリオがそのシーンに用意したカードから1枚を出す。出したカードの結果のとおりに、次のシーンへ進む
- **GM へ提案する** — 手札に無いことを文章で提案する

## 提案

- 提案は、遊んでいるゲームの外へ、開発への要望として届く
- いまは GM がいないので、提案に答える人がいない。提案したシーンは「提案待ち」になり、提案が実装されるまで先へ進めない
- 提案が実装されたら、提案したシーンの続きから遊べる。そこまでに遊んだことはそのまま残る

## キャラクター

- キャラクターは、まず名前だけを持つ
