# コンセプト

## 遊びながら育つカードTRPG

プレイヤーはカードを手札にして、シーンごとに手札を出すか、GM へ提案する（[遊びの共通の形](../cartagraph/index.md)）。手札に無いことを思いついたら、それは提案になり、開発への要望として残る。要望を実装すると、シナリオと機能が増え、次に遊ぶ人はその続きを遊べる。

遊ぶことがそのまま次の版の設計になる。最初は冒険者登録の試験の1シーンから始め、提案で広げていく（[ロードマップ](../roadmap.md)）。

## 人間の役割

- **プレイヤー** — 遊んで、手札を出すか提案する
- **開発者（人間と AI）** — 提案を受け取り、シナリオか機能として実装する。進め方は[開発プロセス](../process/index.md)

## この章の設計原則

- 一度に全部を作らない。プレイヤーとして遊べる土台から始め、GM・セッション・複数のプレイヤーは、提案から要ると分かってから作る
