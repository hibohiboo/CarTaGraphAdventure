- 持ち込み元：`D:\projects\cartagraph\CarTaGraphFantasy`（main、`cb7b0f9` の時点。以下「元」）

## 1. 概要

元のリポジトリから、開発サイクル・要望とダッシュボード・体制の進化ログ・DDD の文書・RDRA のトレース・git フック・CI を持ち込む。ゲームの仕様・シナリオ・画面は持ち込まない。開発の速さの足を引っ張る検査は置いていき、要るとわかったら足す。

持ち込みは「元のファイルをコピーして、要らない部分を削る」で進める。一から書き直さない（元で動いているものを壊さないため。削った結果が動くことは、元のテストを持ち込んで確かめる）。

## 2. 背景

- 元では、GM・セッション・プレイヤー・シナリオを一度に、つじつまを合わせて作ろうとして疲れてしまった（[ロードマップのデザイナーノート](../notes/roadmap.md)）
- 2026-10-30 の人間の判断：DDD と RDRA の部分はすべて持ち込み、アイデアから実装までの進み具合を追えるようにする。骨と、開発や進化を動かす部分もすべて持ち込む。リスクを許して、開発の速さの足を引っ張る過剰な検査は置いていき、要るとわかったら足す
- MSW は置いていく（同日の判断）
- API ドキュメントは確かめていきたいので持ち込む（同日の人間の判断）。API ドキュメントは `packages/schemas` の API の一覧から作るので、`packages/schemas` は仕組みの部分だけを持ち込む（D9）
