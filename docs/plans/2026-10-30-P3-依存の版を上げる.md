# 依存の版を上げる

- 要望：[依存の版を上げる](../backlog/dependency-upgrade.md)
- 状態：完了。PR #1 をマージした（2026-10-31）。人間レビューは合格、振り返りも済んでいる（「人間レビューの結果」）。T7 のメモ：`trace.mjs` の `fail` のうち 37・65 行目は、書き換え前のテストでも落ちない（既存の抜けで、今回増えたものではない）

## 1. 概要

骨の持ち込み（P1）で前のリポジトリの lockfile のまま止めていた依存を、mermaid を除いて最新の版に上げる。メジャーの更新（TypeScript 7・Vite 8・React Router 8・Vitest 5・jsdom 30・jest-dom 7・@vitejs/plugin-react 6）も含む。版を上げて壊れる設定・スクリプトを直し、Biome 2.6 の新しいテストの lint のルールに当たる既存のテストを直して、そのルールを error で効かせる。あわせて MSW（3）を依存と worker まで持ち込む（ハンドラと起動は作らない）。

アプリの振る舞いは変えない。変わっていないことを、既存のテスト・E2E・ビルド・ブラウザでの確かめで示す。

## 2. 背景

- P1 の R2 で、動くとわかっている版で始めるため、前のリポジトリの `pnpm-lock.yaml` を持ち込んだ。lockfile 無しで入れたときの差は[要望](../backlog/dependency-upgrade.md)に書いてある
- 正式仕様（`docs/cartagraph/`・`docs/concept/`・用語集）には触れない。未解決論点にも触れない
- 2026-10-30 に、スクラッチパッドの別の worktree で `pnpm up -r --latest` を試し、全部の検査を流して壊れる箇所を確かめた（下の「試しに上げてわかったこと」）。プランの AI レビューでも、同じ手順で作り直した worktree（mermaid を 11 に戻し、msw 3 を足したもの）で前提を確かめた。プランの詳細設計は、これらの結果を前提にしている

### 課題

骨の持ち込み（P1）で前のリポジトリの lockfile のまま止めていた依存が古い。mermaid を除いて最新に上げ、版を上げて壊れる設定・スクリプトを直す。Biome 2.6 の新しいテストの lint のルールに当たる既存のテストも直す。あわせて MSW 3 を依存と worker まで持ち込む（ハンドラと起動は作らない）。アプリの振る舞いは変えない。

- プラン：[docs/plans/2026-10-30-P3-依存の版を上げる.md](docs/plans/2026-10-30-P3-依存の版を上げる.md)
- 要望：[docs/backlog/dependency-upgrade.md](docs/backlog/dependency-upgrade.md)
