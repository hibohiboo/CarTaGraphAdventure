# NPC と会話する場面を、会話の画面で遊べる

2026-10-31、P4（試験の最初のシーン）の人間レビューで、スマホで遊んだ人間の要望。「会話モードの画面とかにしたいですね。ミルダの会話の前までは今の感じでよいですが、ミルダと会話しているときは画面の上部に NPC カード、真ん中が会話エリア（LINE などのチャットアプリ風）、下部が今のように手札と自分キャラカードのような見た目でどうでしょう」。

P4 の受け入れ条件（名前を入力するところまで）の外で、シナリオのデータの形を変えるので、P4 とは別のサイクルで作る。プランで詰めることの候補：

- シナリオのデータで、どのシーン（あるいはシーンの中のどこから）が会話か、段落ごとに誰の台詞か、NPC（名前・カードの見た目）をどう持つか
- 手札を出したとき、自分の台詞（例：名乗ると「アリサです」）を会話に足すか
- 自分のキャラクターのカードに何を出すか（名乗る前は何と出すか）
- 会話の前の紙面から会話の画面への切り替わり方
