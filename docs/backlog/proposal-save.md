# GM へ提案した文章が、要望のファイルとして保存できる

ロードマップ playable-scene の完成の条件2〜4（提案が開発サーバーから要望のファイルになり、シナリオとシーン、そこまでのイベントの列が入る／完了していない提案があるビートは提案待ちで止まる／公開版でも遊べ、提案の保存は開発サーバーのときだけ）を満たす要望。2026-10-31、人間の依頼「次の、要望がゲームから保存できるところをすすめて」で着手した。

保存先を開発サーバーの口から `docs/backlog/` にすることと、止めを要望ファイルの状態から決めることは、キックオフで決めている（[ロードマップのデザイナーノート](../notes/roadmap.md)）。プランの質問で決めたこと（イベントの列を最小で作る・止めは完了か見送りで外す・重ねて提案できる・会話は読み切ってから・公開版では隠す・文は1〜4000文字・スマホの LAN からも受け付ける）は[プラン](https://github.com/hibohiboo/CarTaGraphAdventure/blob/main/docs/plans/2026-10-31-P6-%E6%8F%90%E6%A1%88%E3%81%AE%E4%BF%9D%E5%AD%98.md)にある。
