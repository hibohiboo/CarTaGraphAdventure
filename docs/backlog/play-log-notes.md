# 会話の合間に、キャラクターの思ったことをメモしてプレイログに残せる

2026-10-31、P5（会話の画面）のプラン作成の中で出た人間の要望。「会話シーンでは、セリフの間に自分のキャラがどんなことを感じたなどメモできるようにする（チャットイメージといっていたのはそのあたり）。将来、GM と PL のチャットで進められるようにしたいが、今の時点では対話がないので、自分の思ったことをプレイログに残せることを要望とする」。

メモを残す入れ物（`PlayState.log`。仮の形）は、P5 の会話の画面で作る。この要望は、その後に、ログに「思ったこと」の種類を足してメモを書けるようにするサイクル。P5 の完了後に着手する。

プランで詰めること：

- メモを書ける位置（台詞の後ごとに書くか、会話エリアの下にいつでも書けるか）
- メモの決まり（文字数の上限・空は断る・編集と削除ができるか）
- 会話エリアでの見た目（自分の吹き出しとは別の、思考のような見せ方）
- ログに入る種類（`note`）と、会話の履歴の範囲（`conversationHistory`）に含めるか
- 将来の GM と PL のチャットへつなげるときに、メモをどう扱うか（いまは決めない。`docs/notes/roadmap.md`「今は作らないもの」）
