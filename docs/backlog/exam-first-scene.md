# 試験の最初のシーンで名乗れる

2026-10-31 の人間の要望。「`npm run web:dev` でプレイできる環境を作ってください。キャラクターの名前を入力するところまで」（このリポジトリは pnpm なので `pnpm web:dev`）。

チャットで GM が演じた試験の冒頭（受付で試験官ミルダに名前を書くよう言われる）を、アプリの最初のシーンにする。手札は「名乗る」の1枚だけで、GM へ提案するボタンはまだ出さない（提案の保存は playable-scene の別の要望で作る）。

あわせて、core-loop のうち、シーン・手札・キャラクターの名前の最小の型と純粋関数、シナリオの JSON を先に作る（イベントの列は作らない）。
