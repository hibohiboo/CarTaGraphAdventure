# イベントの流れ

誰が何をし（コマンド）、どの集約が受け、何が起き（イベント）、それを受けて何をするか（ポリシー）を、時間の順に並べる。ドメイン駆動設計のイベントストーミングの結果にあたる。[集約とドメインイベント](aggregates.md)・[中核のユースケース](use-cases.md)を、1回の遊びの流れとして通して読めるようにし、抜けを見つけるため。

## 書き方

| 要素 | 意味 | 例 |
|---|---|---|
| アクター | コマンドを出す人 | プレイヤー |
| コマンド | アクターがしたいこと | 手札を出す |
| 集約 | コマンドを受けて、不変条件を守って変わるもの（[集約の一覧](aggregates.md#集約の一覧)） | — |
| イベント | 起きたこと。過去形 | — |
| ポリシー | 「〜が起きたら〜する」。ほかの集約・コンテキストへの反映 | — |

- 流れの表は「アクター｜コマンド｜集約｜イベント｜ポリシー・読みモデル」の5列で書く。1行に複数のイベントは「・」で分ける
- ルールの細部は仕様のページが正。ここには書き写さない
