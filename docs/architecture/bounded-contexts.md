# 境界づけられたコンテキスト

[業務領域](domain-map.md)ごとに、同じ言葉が同じ意味で通じる範囲（コンテキスト）を決める。

## コンテキストの一覧

| コンテキスト | 業務領域 | 主な言葉 |
|---|---|---|
| プレイ | プレイ | シナリオ・シーン・ビート・手札・キャラクターの名前・遊んだことのイベントの列 |
| 提案の取り込み | 提案の取り込み | 提案・要望（`docs/backlog/` のファイル）・提案待ち |

「提案の取り込み」は、いまは要望のファイルを作る口（開発サーバー）と、要望の状態から提案待ちを決める読みモデルだけ。振り分けて開発サイクルに乗せる手順は proposal-loop で決める（[ロードマップ](../roadmap.md)）。
