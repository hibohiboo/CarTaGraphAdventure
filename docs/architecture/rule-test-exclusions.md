# ルールのテストの対象外の一覧

ルールのページの節のうち、テストで確かめる性質でない節を「対象外」と宣言する一覧。仕様のページ（`docs/cartagraph/`）にはテストの話を書かず、ここに1か所で置く。

- **ページ**：ルールのページのファイル名（`.md` なし。例：`index`）
- **節**：見出しの文字そのまま。空にすると、そのページ全体が対象外
- **理由**：なぜテストで確かめないかを1行で（`|` は書けない）

どの節を載せるかは、[テストのルール](../process/rules/testing.md)の「ルールのテストのタグ」が正。
